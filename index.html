Public modules

  • go.stealthscale.io/cli
    public go

    The package cli runs command-line programs whose options are the fields of Go structs. It derives the flag, the environment variable and the config key of each field. It converts every source to the type of the field and applies the sources in one order. A handler receives its options as typed values.
